# Security Policy

## Reporting a Vulnerability

Do not disclose vulnerabilities publicly before maintainers have had a reasonable opportunity to investigate.

Report suspected vulnerabilities through GitHub's private vulnerability reporting feature for the Toolip repository.

Include:

- affected version
- reproduction steps
- expected and observed behavior
- impact
- suggested remediation, if known

## Supported Versions

Security fixes are provided for the latest stable release. Older releases may be deprecated when they contain known packaging or security defects.

## Security Principles

Toolip is local-first, redacts secret evidence, avoids uploading project data by default, and requires explicit authorization for remote repository or publishing operations.
